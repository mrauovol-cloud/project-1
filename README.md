# 🍄 Python Mario Game

## 📌 Описание
Python Mario Game — это 2D-платформер, вдохновлённый классическим Марио.  
Игрок проходит уровни, собирает монеты, избегает врагов и добирается до финиша.

## 🚀 Возможности
- 🎮 Управление персонажем (прыжки, движение)
- 🪙 Система сбора монет
- 🗺 Несколько уровней
- 💀 Враги и препятствия
- 🏁 Переход между уровнями
- ❤️ Система жизней / очков

## 🛠 Технологии
- Python 3
- Pygame
- JSON
- OOP (объектно-ориентированное программирование)

## 🎮 Управление
- ⬅️ ➡️ — движение
- ⬆️ / Space — прыжок
- ESC — выход
